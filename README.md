# Heart-Disease-Prediction-Using-Logistic-Regression

This project marks my first hands-on experience with machine learning. It uses Logistic Regression to predict the likelihood of heart disease based on clinical features. The workflow includes data preprocessing, splitting into training and test sets, model training, and evaluation using key metrics such as accuracy, precision, recall, F1-score, and ROC-AUC. It also includes visualization through ROC and Precision-Recall curves to better understand model performance. This project demonstrates a complete, reproducible machine learning pipeline and serves as a foundation for exploring more advanced models in the future.
